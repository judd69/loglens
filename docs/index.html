What it does

Four formats

JSON lines, Python logging, syslog, and access logs — auto-detected per line.

Bursts, not just counts

Finds the busiest windows and the windows with the worst error rate.

Trace one ID

--trace req-2001 returns every entry for that request, in order.

CI gate

--fail-on error exits 1 when errors are present. Clean runs exit 0.

Run it

python3 -m loglens examples/app.log

python3 -m loglens --output html examples/app.log examples/access.log > report.html

Python 3.8+, standard library only. No dependencies to install, nothing to break.
